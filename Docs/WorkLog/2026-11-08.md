## 금일 작업 내용

- `PlayerMovement` 생성
  - `InputActionReference`의 `performed`/`canceled` 이벤트로 이동 입력 수신
  - `transform.Translate`를 이용한 XZ 평면 8방향 이동 구현
- `TopDownCamera` 생성
  - `LateUpdate`에서 `Vector3.Lerp`로 플레이어 위치 + 오프셋을 따라가는 카메라 추적 구현
- `PlayerAim` 생성
  - 마우스 포지션으로 조준 UI(`Image`) 위치 갱신
  - `ScreenPointToRay` + `Physics.Raycast`로 지면 지점을 구해 플레이어가 해당 방향을 바라보도록 회전
- `IDamageable` 인터페이스, `PlayerHealth` 생성
  - 최대 체력 100 기준 `TakeDamage`, `Heal` 구현 (0 ~ 최대 체력 범위 제한)
  - 체력 0 이하 시 `Die` 호출
- `Bullet`, `PlayerShooter` 생성
  - 마우스 좌클릭 입력 시 `_firePoint` 위치·회전으로 `Bullet` Prefab 생성
  - 총알은 전방으로 이동하며 5초 후 `Destroy`

## 막히거나 헤매었던 부분

- Gamepad 오른쪽 스틱으로 조준이 작동하지 않는 문제
  - 상황 : `IA_Player.inputactions`의 `Aim` 액션에 `<Mouse>/position`과 `<Gamepad>/rightStick`이 함께 바인딩되어 있으나, Gamepad 오른쪽 스틱으로는 조준이 작동하지 않음
  - 원인 : 미확인
  - 결과 : 미해결
