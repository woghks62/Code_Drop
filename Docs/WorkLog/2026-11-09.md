## 금일 작업 내용

- `Bullet` 충돌 감지 및 데미지 처리
  - `OnTriggerEnter`에서 `GetComponentInParent<IDamageable>()`로 피격 대상을 찾아 `TakeDamage` 호출
  - 충돌 시 총알 `Destroy`
- CSV 기반 무기 스탯 데이터 구현
  - `GunStats` ScriptableObject 생성 (ID, 이름, 데미지, 연사 간격, 탄창 용량, 예비 탄창 수, 재장전 시간, 탄 퍼짐)
  - `GunTable.csv`에 Rifle, ShotGun, Sniper, Pistol 4종 스탯 작성
  - `GunTableParser`에서 CSV의 헤더 3줄을 건너뛰고 각 행을 `TryParse`로 변환해 `GunStats.SetData`로 반영
  - `Gun` 컴포넌트가 `GunStats`를 참조하도록 구성
- `PlayerShooter` 사격 방식 변경
  - 좌클릭 `performed`/`canceled`로 `_isShooting`을 토글하고, `Update`에서 `FramingInterval` 기준으로 연사
  - 무기 스탯의 데미지를 `Bullet.Damage`에 전달
  - `BulletSpread`를 이용한 탄 퍼짐 적용, ShotGun은 1회 발사 시 총알 10발 생성
- 무기 재장전 구현
  - `IA_Player.inputactions`에 재장전 액션 추가
  - 코루틴 `ReloadRoutine`에서 `ReloadTime`만큼 대기 후 탄창을 채우고 예비 탄창 1 감소
  - 탄창이 가득 찼거나 예비 탄창이 0이면 재장전하지 않고, 재장전 중에는 사격 불가
- 무기 교체 기능 구현 (진행 중)
  - `WeaponChange` 생성, 무기 1·2 입력 시 `PlayerShooter.ChangeWeapon` 호출
  - `PlayerShooter`가 현재 무기 스탯을 필드로 복사해 사용하도록 변경
