# 시스템 기술 문서 작성 규칙

> 시스템 기술 문서를 작성할 때의 규칙.
>
> 기술 문서 작성 양식은 `@Docs\Template\Tech Doc Template.md` 를 참고.
>
> 해당 문서는 각 섹션에 대한 작성 규칙을 정의한다.

## 1. 제목 / 개요

- 제목은 `[시스템명] 시스템` 형식으로 작성한다.
- 개요는 시스템이 하는 일을 한 줄로 요약한다.
- 관련 Issue 번호를 기재한다. 여러 Issue에 걸친 경우 Issue별 작업을 괄호로 구분한다.
- 관련 Issue가 없으면 `관련 Issue` 줄을 생략한다.
- 예시 :
    ```markdown
    # 상품 상호작용 시스템

    > 1인칭 플레이어가 바라보는 상품을 감지하고, 집어 운반하고 내려놓는 시스템.
    >
    > 관련 Issue : #5 (감지), #7 (집기 및 운반), #9 (놓기)
    ```

## 2. 클래스 구성과 책임

- 시스템을 구성하는 클래스의 이름, 파일 위치, 책임을 표로 작성한다.
- 책임은 해당 클래스가 실제로 수행하는 일을 기준으로 작성한다.
- 표 아래에 클래스 간 관계를 mermaid `classDiagram`으로 그린다.
    - 다른 클래스나 Inspector와 관련된 필드, 외부에서 사용하는 프로퍼티·메서드만 표시한다.
- 다른 시스템과의 참조 관계나 독립성은 다이어그램 아래에 리스트로 기재한다.

## 3. 동작 흐름

- 시스템의 주요 처리 흐름을 mermaid `flowchart`로 그린다.
- 흐름이 여러 개라면 하위 섹션(`###`)으로 나눈다.
- 섹션 이름은 시스템에 맞게 바꿀 수 있다. (예: `2. 생성 흐름`)
- 다이어그램 아래에 흐름만으로 드러나지 않는 동작 특성과 주의점을 리스트로 기재한다.

## 4. Inspector 설정 가이드

- 시스템을 씬에 구성하는 방법을 작성한다.
- `오브젝트 구성`에는 관련 오브젝트의 계층 구조와 붙어 있는 컴포넌트를 기재한다.
- 컴포넌트마다 하위 섹션을 두고, Inspector 필드와 설명을 표로 작성한다.
    - 필드가 비어 있을 때의 동작(Error 로그 등)이 있다면 함께 기재한다.
    - 테스트에 사용한 값이 있으면 `테스트 값`으로 기재한다.
- 레이어, Prefab 조건, 디버그 표시 등 설정에 필요한 내용이 있으면 하위 섹션을 추가한다.
- `테스트 환경`에는 시스템을 확인할 수 있는 씬 경로를 기재한다.

## 5. 설계 결정 기록

- 구현 과정에서 내린 설계 결정을 `항목 / 결정 / 이유` 표로 작성한다.
- 다른 방식과 비교해 선택했다면 `이유`에 비교한 방식을 함께 기재한다. (예: `Linecast와 비교 후 선택`)
- 이유의 근거가 프로젝트 규칙 문서에 있으면 문서와 섹션 번호를 함께 기재한다. (예: `ARCHITECTURE.md 04-5`)
- 의도적으로 구현하지 않은 기능은 결정을 `미구현`으로 쓰고 이유를 기재한다.
- 결정의 이유를 코드로부터 추측하지 않는다.
    - 사용자에게 확인받은 이유만 기재한다.
    - 확인되지 않은 항목은 `이유`를 비워두고 보고한다.

## 6. 기타

### 작성 기준

- 문서 내용의 출처는 **실제 소스코드와 사용자가 제공한 정보**뿐이다.
- 코드로 확인할 수 없는 내용(씬·Prefab 설정값, Play 테스트 결과 등)은 사용자에게 확인받은 내용만 기재한다.
    - 확인되지 않은 동작은 항목 끝에 `(미검증)`을 표기한다.
- 기존 문서를 수정할 때는 이번 작업과 관련된 부분만 수정한다. 다른 부분의 문제는 사용자에게 보고만 한다.
- 규칙 문서의 내용을 기술 문서에 옮겨 적지 않는다. 필요하면 규칙 문서와 섹션을 가리킨다.
- 코드, 클래스, 메서드, 파일명 등은 백틱(`)으로 감싸 작성한다.

### 파일 위치

- 기술 문서는 `Docs\Systems\` 폴더에 저장한다.
- 파일 이름은 시스템을 나타내는 PascalCase 영문으로 한다. (예: `PlayerInteraction.md`)
- 새 문서를 만들면 `CLAUDE.md`의 `온디맨드 참조 - 시스템 기술 문서`에 등록이 필요함을 사용자에게 알린다.
